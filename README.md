# Iron Pulse Gym website
Static site, no build, no dependencies. Plain HTML/CSS/JS – deploy anywhere (Cloudflare Pages, Netlify, GitHub Pages).

Sections: hero, programs, why us, membership plans (monthly / quarterly / yearly toggle), trainers, class timetable (opens on today), BMI calculator, member reviews, free-trial booking, FAQ, map & contact, floating WhatsApp button.

All enquiries (free trial, "Join plan") open WhatsApp with a pre-filled message – no server needed.

Edit `index.html`:
- Gym name, phone, photos, plans, trainers and classes: the `EDIT HERE` block at the top of the script.
- Phone number also appears in the HTML: search `918302615834`.
- Address / map: search `Ranivara`.
- Photos: use your own by putting images in a `photos/` folder and using `/photos/name.jpg`. If a photo fails to load, a coloured gradient shows instead.

Logo / favicon: `logo.svg`.
